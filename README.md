# The Garmendia Experience 2026

![Portada de The Garmendia Experience 2026](assets/home.png)

Sitio web estático dedicado a Germán Garmendia, creador de contenido, músico y figura destacada de internet en habla hispana.

La web presenta una experiencia visual e interactiva que recorre su historia, trayectoria, música, redes sociales y momentos importantes de su carrera. Incluye animaciones, secciones con imágenes, línea de tiempo horizontal, galería visual y enlaces a sus plataformas principales.

## Tecnologías usadas

- HTML
- CSS
- JavaScript
- GSAP + ScrollTrigger
- Font Awesome
- Google Fonts

## Estructura del proyecto

- `index.html`: estructura principal del sitio
- `style.css`: estilos, diseño responsive y animaciones visuales
- `main.js`: interacciones y animaciones con JavaScript
- `assets/`: imágenes utilizadas en la web
- `vinilo.gif`: animación usada en la sección musical

## Cómo ver la web

Abrir el archivo `index.html` en cualquier navegador moderno.
